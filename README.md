# ia assistant
first install ollama
for windows
```powershell
irm https://ollama.com/install.ps1 | iex
```
for linux
```bash
curl -fsSL https://ollama.com/install.sh | sh
```
then install llama3.2
```powershell
ollama pull llama3.2
```
and then run terminal or web version
terminal
```bash
python terminal.py
```
or web
```bash
python main.py
```
